1. Ce que fait l'application

Une seule personne (RH, office manager ou dirigeant) gère tous les congés de l'entreprise depuis un seul écran : elle saisit un congé en moins de 10 secondes, voit qui est absent, est prévenue des conflits et exporte le récapitulatif pour la paie.

  • Les soldes ne sont jamais tapés à la main. Chaque solde est la somme d'écritures dans un journal (acquisition, congé pris, ajustement…). Une erreur se corrige par une nouvelle écriture, jamais en effaçant.
  • Prévenir sans bloquer. Seules les données impossibles sont bloquées (dates qui se chevauchent, aucun jour ouvré…). Le reste est un avertissement : vous restez décisionnaire.
  • Tout est réversible. Chaque action affiche « Annuler » pendant 6 secondes, et tout est tracé.
  • Unité : le jour, par pas d'une demi-journée. Interface en français et en anglais.

2.2 Installer les dépendances

Ouvrez un terminal dans le dossier du projet (celui qui contient package.json) et lancez :

pnpm install

2.3 Créer le fichier de configuration .env

Dans le même dossier, créez un fichier texte nommé exactement .env avec ce contenu (remplacez les valeurs en MAJUSCULES) :

NODE_ENV=development
PORT=3000
DATABASE_URL=postgres://postgres:MOT_DE_PASSE_POSTGRES@127.0.0.1:5432/leave
APP_URL=http://localhost:5173
BETTER_AUTH_SECRET=UNE_LONGUE_CHAINE_ALEATOIRE_DE_32_CARACTERES_OU_PLUS
OPERATOR_EMAIL=rh@votre-entreprise.com
OPERATOR_INITIAL_PASSWORD=UN_MOT_DE_PASSE_PROVISOIRE
SEED_LOCALE=fr
  • Pour générer le secret : node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
  • Si le mot de passe PostgreSQL contient @ : / #, encodez-le (par exemple @ devient %40).
  • Laissez les réglages e-mail (SMTP_…) vides au début : les e-mails (invitations, réinitialisations) s'affichent alors dans le terminal.
Important : le fichier .env contient des secrets. Ne l'envoyez jamais par e-mail et ne le partagez pas.

2.4 Préparer la base de données

pnpm --filter @leave/server db:create
pnpm --filter @leave/server db:migrate
pnpm --filter @leave/server db:seed

db:create crée la base leave, db:migrate crée les tables, db:seed ajoute les types de congé par défaut, les jours fériés tunisiens, une règle de congé payé de 22 jours par an et le compte RH défini dans .env. Ces commandes peuvent être relancées sans risque.

2.5 Lancer l'application

pnpm dev

Attendez les lignes Leave app listening on http://localhost:3000 et Local: http://localhost:5173/, puis ouvrez http://localhost:5173 dans votre navigateur. Pour arrêter : Ctrl+C dans le terminal.

Après une mise à jour du code : pnpm install, puis pnpm --filter @leave/server db:migrate, puis pnpm dev.

3. Première connexion et sécurité

  1. Sur la page Connexion RH, saisissez l'e-mail et le mot de passe provisoire du fichier .env.
  2. L'application vous demande aussitôt de Choisir votre mot de passe : au moins 8 caractères, et pas un mot de passe courant (« azerty123 », « password1 »… sont refusés).
  3. Rester connecté coché : la session dure 30 jours sur cet appareil. Sinon : 12 heures, et elle se ferme avec le navigateur.
  • 5 essais de mot de passe erronés verrouillent le compte pendant 15 minutes. Le message ne dit jamais si l'e-mail existe.
  • Mot de passe oublié ? envoie un lien valable 30 minutes, utilisable une seule fois.
  • Le bouton de langue (FR/EN) de la barre du haut change la langue de l'interface. Se déconnecter est à côté.

5. Configurer l'application (Paramètres)

Faites ce réglage avant de saisir des salariés. Menu Paramètres, quatre onglets :

5.1 Entreprise

  • Nom de l'entreprise, Semaine de travail (cases jour par jour ou raccourcis Lun–Ven, Lun–Sam, Dim–Jeu), L'année de congés commence en.
  • Autoriser un solde négatif et sa Limite négative (jours). Désactivé : un congé qui rendrait le solde négatif est bloqué.
  • Statut par défaut à l'enregistrement : Approuvé (recommandé) ou En attente.
  • Langue et région : formats des dates et des nombres dans les exports et les e-mails.
  • Visibilité de l'équipe dans le portail : ce que chaque salarié voit des absences de ses collègues : Son service (par défaut), Toute l'entreprise ou Désactivée (l'onglet Équipe disparaît). Voir chapitre 14.
  • Services : ajouter, renommer, ordonner ; un service ne peut être supprimé que s'il est vide.
À noter : le préréglage pays est la Tunisie. Les 22 jours par an de congé payé sont une valeur par défaut modifiable, pas une règle légale : vérifiez-la selon le Code du travail et votre convention collective.

5.2 Types de congé

Cinq types sont créés : congé payé, maladie, sans solde, congé exceptionnel, repos compensateur. Pour chacun : nom, couleur, Payé, Déduit du solde, Jours ouvrés / Jours calendaires, Justificatif obligatoire, plafond annuel, statut par défaut. Un type n'est jamais supprimé : désactivez-le.

5.3 Acquisition

Pour chaque type qui se déduit du solde, saisissez les Jours par année de congés (par exemple 22) et choisissez le mode : Annuel (les 22 jours sont donnés d'un coup au début de l'année de congés) ou Mensuel (ils sont gagnés mois par mois). Cochez Proratiser le mois d'embauche pour qu'un salarié arrivé en cours de mois ne gagne que les jours travaillés. À l'enregistrement, l'application demande : À partir d'aujourd'hui ou Dès le début de l'année de congés. L'historique des règles est conservé.

En mode Mensuel, 22 jours par an font environ 1,83 jour par mois (≈ 0,06 par jour sur un mois de 30 jours). Comme les soldes comptent par demi-journée, les mois sont crédités 2 ; 1,5 ; 2 ; 2 ; 1,5… et le total de l'année est exactement 22 : le reste d'un mois est reporté au suivant, rien n'est perdu. La colonne Droits annuels d'un salarié remplace les 22 jours pour lui seul.

5.4 Jours fériés

Les jours fériés tunisiens sont fournis : 1er janvier, 20 mars (Indépendance), 9 avril (Martyrs), 1er mai, 25 juillet (République), 13 août (Femme), 15 octobre (Évacuation), 17 décembre (Révolution). Les fêtes religieuses (Aïd el-Fitr, Aïd el-Idha, Ras el-Am el-Hijri, Mouled) suivent le calendrier lunaire : leurs dates sont estimées et marquées Date à confirmer. Corrigez-les dès l'annonce officielle. Ajouter un jour férié permet aussi une demi-journée ou une Fermeture d'entreprise.

Si un changement touche des congés déjà saisis, une fenêtre les liste avec l'ancien et le nouveau nombre de jours. Cliquez Recalculer ces congés pour corriger les jours et les soldes, ou Pas maintenant.

6. Ajouter les salariés

Menu Salariés (raccourci E).

  • Ajout rapide : la dernière ligne du tableau est vide. Tapez le nom, choisissez le service (ou + Nouveau service), la date d'embauche, puis Entrée : la ligne suivante s'ouvre. Vous pouvez aussi saisir des Soldes d'ouverture pour les salariés présents avant l'application.
  • Modifier : double-clic sur une cellule (service, poste, e-mail, code, droits annuels), Tab pour passer à la suivante.
  • Colonnes de solde : le grand chiffre est le disponible ; dessous, « pris · en attente ». Rouge si négatif, orange sous 2 jours.
  • Fiche salarié (clic sur le nom) : cartes de solde, Historique des congés, Journal des soldes par type, avec le solde courant après chaque écriture.
  • Archiver au départ d'un salarié : il disparaît du planning mais reste dans les exports passés. Restaurer l'annule.

Accès au portail

Le menu de chaque ligne propose : Envoyer l'invitation (e-mail avec un lien valable 48 h pour choisir son mot de passe), Mot de passe temporaire pour un salarié sans e-mail (affiché une seule fois, connexion avec son code salarié, changement obligatoire), Activer / Désactiver l'accès au portail, Déconnecter partout. Archiver un salarié ou désactiver son accès le déconnecte aussitôt de tous ses appareils. Mode d'emploi du portail : chapitre 14.

7. Donner des jours : acquisition et soldes

Un nouveau salarié démarre à 0. Deux façons de lui donner des jours :

  1. Acquisition mensuelle : Paramètres → Acquisition → Lancer l'acquisition. Choisissez le mois, cliquez Aperçu (liste des salariés, types et jours), puis Lancer l'acquisition de … et confirmez. À faire chaque début de mois. Relancer le même mois n'ajoute rien : les lignes « Déjà fait » sont ignorées.
  2. Ajustement manuel : fiche salarié → Ajuster le solde : type, jours (+ ou −, par demi-journée), Date d'effet, Note (obligatoire) → Appliquer l'ajustement.

Arrondi : le total gagné depuis le début de l'année de congés est arrondi à la demi-journée la plus proche, et chaque mois reçoit la différence. Exemple : embauché le 16 novembre (30 jours), il gagne 15 × 0,06 ≈ 0,92 jour → 1 jour crédité en novembre, puis 2 en décembre.

Mise à jour depuis une version précédente : la règle se saisit désormais en jours par an. Ouvrez Paramètres → Acquisition, saisissez 22, enregistrez et choisissez Dès le début de l'année de congés. Les mois déjà crédités à l'ancien taux ne sont pas modifiés : corrigez l'écart par un ajustement manuel si besoin.

8. Saisir un congé en 10 secondes

Ouvrez le formulaire avec C, le bouton + Saisir un congé, ou un clic sur une case vide du planning (salarié et date déjà remplis).

  1. Salarié : tapez 2 ou 3 lettres, Entrée. Les 5 derniers utilisés apparaissent en premier.
  2. Type : congé payé par défaut ; les touches 1 à 9 changent de type.
  3. Dates : premier et dernier jour, ou les raccourcis Aujourd'hui, Demain, Cette semaine, Semaine prochaine.
  4. Demi-journées : premier jour Journée / Après-midi, dernier jour Journée / Matin (un seul jour : Journée, Matin ou Après-midi).
  5. Vérifiez la ligne en direct, par exemple « 4,5 jours ouvrés (1 week-end, 1 jour férié exclu(s)) », et l'aperçu du solde « Congé payé : 12 → 7,5 jours » (rouge si négatif).
  6. Enregistrez : Ctrl+Entrée (statut par défaut) ou Maj+Ctrl+Entrée (en attente). Un bandeau Annuler reste 6 secondes.

Facultatif : note, et pièce jointe (glisser, coller ou choisir un PDF, JPG ou PNG de 10 Mo max). Un trombone signale un justificatif obligatoire manquant.

Si vous quittez le formulaire avec des modifications non enregistrées (Échap, bouton Retour du navigateur, un lien du menu), l'application demande confirmation avant de les abandonner.

10. Le planning et les chiffres clés

  • Une ligne par salarié, regroupés par service (cliquez sur un service pour le replier). Sous chaque service, une ligne indique combien de personnes sont absentes chaque jour.
  • Couleur = type de congé ; barre pleine = approuvé, hachurée = en attente ; demi-barre = demi-journée.
  • Week-ends et jours fériés grisés (nom au survol), trait vertical pour aujourd'hui.
  • Zoom W semaine / M mois ; ← → période précédente / suivante ; T aujourd'hui.
  • Filtres service, type, statut et recherche : conservés pendant la session et appliqués aussi aux cartes de chiffres clés.
  • Clic sur une barre : ouvre le congé. Clic sur une case vide : nouveau congé prérempli.

11. Rapports et exports paie

Menu Rapports. Choisissez la période : Mois, Trimestre, Année ou Personnalisée.

  • Récapitulatif mensuel de paie : une ligne par salarié, jours pris par type, jours sans solde, solde en début et en fin de période. Un congé à cheval sur deux mois est réparti jour par jour.
  • Détail des congés : une ligne par congé de la période.
  • Aperçu à l'écran, puis téléchargement en XLSX (Excel) ou CSV. Le CSV s'ouvre directement dans Excel (séparateur « ; » et virgule décimale en français).
  • Le bouton Exporter de la barre du haut exporte en un clic la paie du mois en cours, dans le dernier format utilisé.
  • Les salariés archivés restent dans les exports des périodes où ils étaient présents.

13. Comprendre les soldes

  • Solde = somme des écritures du journal jusqu'à la date du jour.
  • Disponible = solde − jours en attente (réservés).
  • Approuver écrit une ligne « Congé » négative ; annuler ou refuser un congé approuvé écrit une « Contre-passation » positive. Rien n'est jamais effacé.
  • À la saisie, le contrôle tient aussi compte des congés déjà approuvés plus tard dans l'année, pour ne pas dépenser deux fois les mêmes jours. L'aperçu peut donc être plus bas que le chiffre du tableau des salariés.

14. Le portail salarié

Chaque salarié a son propre espace, pensé pour le téléphone : il consulte ses soldes et demande un congé en 15 secondes. Il ne voit que ses propres données ; de ses collègues, il voit seulement qui est absent et quand.

14.1 Donner l'accès (côté RH)

  1. Menu Salariés, menu de la ligne du salarié.
  2. Salarié avec e-mail : Envoyer l'invitation. Il reçoit un lien valable 48 h, choisit son mot de passe et arrive dans son espace.
  3. Salarié sans e-mail : Mot de passe temporaire. Notez l'Identifiant de connexion (son code salarié) et le mot de passe, affichés une seule fois, et remettez-les-lui. Il devra choisir son propre mot de passe à la première connexion.

Adresse du portail : http://localhost:5173/me en local, ou https://votre-domaine/me une fois en ligne. Sur ordinateur, il s'affiche en colonne centrale.

14.2 Se connecter (côté salarié)

  • Page Mon espace congés : E-mail ou code salarié, mot de passe, Se connecter. Mêmes règles que pour les RH : 8 caractères minimum, verrouillage 15 minutes après 5 erreurs, Rester connecté 30 jours.
  • Mot de passe oublié : Mot de passe oublié ? si le salarié a un e-mail ; sinon, il demande un nouveau mot de passe temporaire aux RH.
  • La roue dentée en haut à droite ouvre les Réglages : Langue, Changer mon mot de passe, Se déconnecter.

14.5 Retirer une demande

Tant qu'elle est En attente, une demande peut être retirée avec Retirer, sans confirmation : Annuler la remet en attente pendant 6 secondes. Si les RH ont déjà décidé, le retrait est refusé (« Les RH ont déjà statué sur cette demande »). Un congé approuvé ne se modifie pas depuis le portail : il faut contacter les RH.

14.6 Synchronisation en direct

  • Une demande envoyée apparaît chez les RH en 2 secondes environ : le chiffre Demandes en attente augmente, une barre hachurée s'affiche et la demande porte le marqueur Via le portail.
  • Quand les RH approuvent ou refusent, l'écran du salarié se met à jour tout seul, solde compris. Un e-mail est aussi envoyé : il ne contient que les dates et la décision ; le type et le motif ne sont visibles qu'après connexion.
  • Si la connexion en direct est coupée, les écrans se rafraîchissent quand même toutes les 30 secondes.
Téléphone partagé : se déconnecter efface du téléphone les demandes en attente d'envoi. Si une autre personne se connecte sur le même appareil, elle ne voit et n'envoie jamais les demandes du salarié précédent.

1. What the app does

One person (HR, office manager or owner) manages every leave for the company from a single screen: logs a leave in under 10 seconds, sees who is away, is warned about conflicts, and exports the payroll summary.

  • Balances are never typed in. Each balance is the sum of entries in a ledger (accrual, leave taken, adjustment…). Mistakes are corrected with a new entry, never by erasing.
  • Warn, don't block. Only impossible data is blocked (overlapping dates, no working days…). Everything else is a warning: you stay in charge.
  • Everything is reversible. Each action shows "Undo" for 6 seconds, and everything is logged.
  • Unit: days, in half-day steps. Interface in French and English.

5. Set-up (Settings)

Do this before adding employees. Menu Settings, four tabs:

5.1 Company

  • Company name, Working week (day toggles or the Mon–Fri, Mon–Sat, Sun–Thu presets), Leave year starts in.
  • Allow a negative balance and its Negative limit (days). When off, a leave that would make the balance negative is blocked.
  • Default status on save: Approved (recommended) or Pending.
  • Locale: date and number formats in exports and emails.
  • Team visibility in the portal: what each employee sees of colleagues' absences: their department (default), the whole company, or off (the Team tab disappears). See chapter 14.
  • Departments: add, rename, order; a department can only be deleted when empty.
Note: the country preset is Tunisia. The 22 days of paid leave a year are an editable default, not a legal rule: check them against the Labour Code and your collective agreement.

5.2 Leave types

Five types are created: paid leave, sick leave, unpaid leave, special leave, compensatory rest. For each: name, colour, Paid, Deducts from the balance, Working days / Calendar days, Attachment required, annual cap, default status. Types are never deleted: deactivate them instead.

5.3 Accrual

For each type that deducts from the balance, enter the Days per leave year (for example 22) and choose the mode: Annual (all 22 days granted at the start of the leave year) or Monthly (earned month by month). Tick Prorate the hire month so someone who joins mid-month only earns the days they worked. When you save, the app asks: From today or From the start of the leave year. Rule history is kept.

In Monthly mode, 22 days a year is about 1.83 days a month (≈ 0.06 a day in a 30-day month). Balances count in half days, so months are credited 2, 1.5, 2, 2, 1.5… and the year totals exactly 22: each month's remainder carries to the next, nothing is lost. An employee's Allowance column replaces the 22 days for that person only.

5.4 Public holidays

The Tunisian public holidays are supplied: 1 January, 20 March (Independence), 9 April (Martyrs), 1 May, 25 July (Republic), 13 August (Women's Day), 15 October (Evacuation), 17 December (Revolution). Religious holidays (Eid al-Fitr, Eid al-Adha, Islamic New Year, Prophet's Birthday) follow the lunar calendar: their dates are estimates marked Date to confirm. Correct them as soon as the official date is announced. Add holiday also handles half days and company Closure days.

If a change affects leaves already logged, a dialog lists them with the old and new number of days. Click Recalculate these leaves to fix the days and balances, or Not now.

7. Giving days: accrual and balances

A new employee starts at 0. There are two ways to give days:

  1. Monthly accrual: Settings → Accrual → Run accrual. Choose the month, click Preview (employees, types and days), then Run accrual for … and confirm. Do this at the start of every month. Running the same month again adds nothing: "Already done" rows are skipped.
  2. Manual adjustment: employee drawer → Adjust balance: type, days (+ or −, in half days), Effective date, Note (required) → Apply adjustment.

Rounding: the total earned since the start of the leave year is rounded to the nearest half day, and each month receives the difference. Example: hired on 16 November (30 days), they earn 15 × 0.06 ≈ 0.92 day → 1 day credited in November, then 2 in December.

Upgrading from an earlier version: the rule is now entered in days per year. Open Settings → Accrual, enter 22, save and choose From the start of the leave year. Months already credited at the old rate are not changed: fix any gap with a manual adjustment.

8. Logging a leave in 10 seconds

  2. Type: paid leave by default; keys 1 to 9 switch type.
  3. Dates: first and last day, or the presets Today, Tomorrow, This week, Next week.

13. Understanding balances

  • Balance = sum of ledger entries up to today.
  • Available = balance − pending (reserved) days.
  • Approving writes a negative "Leave" entry; cancelling or rejecting an approved leave writes a positive "Reversal". Nothing is ever erased.
  • When you log a leave, the check also counts leave already approved later in the year, so the same days can't be spent twice. The preview can therefore be lower than the figure in the employees table.

5. الإعداد (الإعدادات)

قم بهذا الإعداد قبل إضافة الموظفين. القائمة ⁦Paramètres⁩، وفيها أربعة تبويبات:

5.1 الشركة ⁦(Entreprise)⁩

  • اسم الشركة، وأيام العمل في الأسبوع (أزرار لكل يوم أو الاختصارات ⁦Lun–Ven⁩ و⁦Lun–Sam⁩ و⁦Dim–Jeu⁩)، وشهر بداية سنة الإجازات.
  • السماح بالرصيد السالب وحدّه بالأيام. إن كان معطّلًا تُمنع الإجازة التي تجعل الرصيد سالبًا.
  • الحالة الافتراضية عند الحفظ: مقبولة (موصى به) أو معلّقة.
  • اللغة والمنطقة: تحدد صيغ التواريخ والأرقام في ملفات التصدير والرسائل.
  • ظهور الفريق في البوابة ⁦(Visibilité de l'équipe dans le portail)⁩: ما يراه كل موظف من غيابات زملائه: ⁦Son service⁩ (قسمه، افتراضي) أو ⁦Toute l'entreprise⁩ (كل الشركة) أو ⁦Désactivée⁩ (معطّل، ويختفي تبويب الفريق). انظر الفصل 14.
  • الأقسام ⁦(Services)⁩: إضافة وإعادة تسمية وترتيب؛ ولا يُحذف القسم إلا إذا كان فارغًا.
تنبيه: الإعداد المسبق للبلد هو تونس. الـ 22 يومًا من الإجازة المدفوعة في السنة قيمة افتراضية قابلة للتعديل، وليست قاعدة قانونية: تحقّق منها وفق مجلة الشغل والاتفاقية المشتركة المعمول بها لديكم.

5.2 أنواع الإجازات ⁦(Types de congé)⁩

تُنشأ خمسة أنواع: إجازة مدفوعة، مرضية، بدون أجر، استثنائية، راحة تعويضية. لكل نوع: الاسم، اللون، مدفوع أم لا، هل يُخصم من الرصيد، أيام عمل أم أيام تقويمية، هل الوثيقة الداعمة إلزامية، السقف السنوي، الحالة الافتراضية. لا يُحذف أي نوع، بل يُعطَّل.

5.3 الاكتساب ⁦(Acquisition)⁩

لكل نوع يُخصم من الرصيد أدخل عدد الأيام في السنة ⁦(Jours par année de congés)⁩، مثلًا 22، واختر الطريقة: ⁦Annuel⁩ (سنوي: تُمنح الأيام الـ 22 دفعة واحدة في بداية سنة الإجازات) أو ⁦Mensuel⁩ (شهري: تُكتسب شهرًا بشهر). فعّل ⁦Proratiser le mois d'embauche⁩ حتى لا يكتسب من التحق في منتصف الشهر إلا أيام عمله. عند الحفظ يسألك التطبيق: ⁦À partir d'aujourd'hui⁩ (من اليوم) أو ⁦Dès le début de l'année de congés⁩ (من بداية سنة الإجازات). ويُحتفظ بتاريخ القواعد.

في الطريقة الشهرية، 22 يومًا في السنة تعادل نحو 1.83 يوم في الشهر (نحو 0.06 يوم عن كل يوم في شهر من 30 يومًا). ولأن الأرصدة تُحسب بأنصاف الأيام، تُضاف الأشهر هكذا: 2 ثم 1.5 ثم 2 ثم 2 ثم 1.5… ويكون مجموع السنة 22 بالضبط: يُرحَّل باقي كل شهر إلى الشهر الموالي ولا يضيع شيء. وعمود ⁦Droits annuels⁩ (الحقوق السنوية) لموظف ما يعوّض الـ 22 يومًا بالنسبة إليه وحده.

5.4 العطل الرسمية ⁦(Jours fériés)⁩

العطل الرسمية التونسية مرفقة: 1 جانفي، 20 مارس (عيد الاستقلال)، 9 أفريل (عيد الشهداء)، 1 ماي (عيد الشغل)، 25 جويلية (عيد الجمهورية)، 13 أوت (عيد المرأة)، 15 أكتوبر (عيد الجلاء)، 17 ديسمبر (عيد الثورة). أما الأعياد الدينية (عيد الفطر، عيد الأضحى، رأس السنة الهجرية، المولد النبوي) فتتبع التقويم القمري: تواريخها تقديرية ومعلَّمة بـ ⁦Date à confirmer⁩ (تاريخ يُؤكَّد لاحقًا). صحّحها فور الإعلان الرسمي. ويتيح زر ⁦Ajouter un jour férié⁩ أيضًا إضافة نصف يوم أو يوم إغلاق للشركة ⁦(Fermeture)⁩.

إذا مسّ التغيير إجازات مسجّلة، تظهر نافذة تعرضها مع العدد القديم والجديد للأيام. انقر ⁦Recalculer ces congés⁩ لتصحيح الأيام والأرصدة، أو ⁦Pas maintenant⁩ للتأجيل.

6. إضافة الموظفين

القائمة ⁦Salariés⁩ (الاختصار ⁦E⁩).

  • الإضافة السريعة: السطر الأخير في الجدول فارغ. اكتب الاسم واختر القسم (أو ⁦+ Nouveau service⁩) وتاريخ التوظيف ثم اضغط ⁦Enter⁩ فيُفتح السطر التالي. ويمكنك أيضًا إدخال أرصدة افتتاحية ⁦(Soldes d'ouverture)⁩ للموظفين الموجودين قبل اعتماد التطبيق.
  • التعديل: نقرة مزدوجة على الخلية (القسم، المنصب، البريد، الرمز، الحقوق السنوية) ثم ⁦Tab⁩ للانتقال.
  • أعمدة الرصيد: الرقم الكبير هو المتاح، وتحته «المأخوذ · المعلّق». أحمر إذا كان سالبًا، وبرتقالي إذا قلّ عن يومين.
  • بطاقة الموظف (انقر على الاسم): بطاقات الأرصدة، وسجل الإجازات، و«سجل الأرصدة» ⁦(Journal des soldes)⁩ لكل نوع مع الرصيد بعد كل قيد.
  • الأرشفة عند مغادرة الموظف: يختفي من المخطط لكنه يبقى في التصديرات السابقة، ويمكن استعادته بزر ⁦Restaurer⁩.

الوصول إلى البوابة

تتضمن قائمة كل سطر: ⁦Envoyer l'invitation⁩ (رسالة برابط صالح 48 ساعة لاختيار كلمة المرور)، و⁦Mot de passe temporaire⁩ للموظف الذي لا بريد له (يظهر مرة واحدة، ويدخل الموظف برمزه ثم يغيّرها إلزاميًا)، وتفعيل أو تعطيل الوصول، و⁦Déconnecter partout⁩ (الخروج من كل الأجهزة). أرشفة الموظف أو تعطيل وصوله يُخرجه فورًا من كل أجهزته. طريقة استعمال البوابة: الفصل 14.

7. منح الأيام: الاكتساب والأرصدة

يبدأ الموظف الجديد برصيد 0. توجد طريقتان لمنحه أيامًا:

  1. الاكتساب الشهري: ⁦Paramètres → Acquisition → Lancer l'acquisition⁩. اختر الشهر وانقر ⁦Aperçu⁩ (معاينة الموظفين والأنواع والأيام)، ثم زر التشغيل وأكّد. كرّر ذلك في بداية كل شهر. إعادة تشغيل الشهر نفسه لا تضيف شيئًا، إذ تُتجاهل الأسطر المنجزة سابقًا.
  2. التعديل اليدوي: بطاقة الموظف ← ⁦Ajuster le solde⁩: النوع، الأيام (+ أو −، بأنصاف الأيام)، تاريخ السريان، ملاحظة إلزامية ← ⁦Appliquer l'ajustement⁩.

التقريب: يُقرَّب مجموع ما اكتُسب منذ بداية سنة الإجازات إلى أقرب نصف يوم، ويُضاف لكل شهر الفرق. مثال: موظف التحق يوم 16 نوفمبر (شهر من 30 يومًا) يكتسب 15 × 0.06 ≈ 0.92 يوم، فيُضاف له يوم واحد في نوفمبر ثم يومان في ديسمبر.

عند التحديث من نسخة سابقة: أصبحت القاعدة تُدخَل بعدد الأيام في السنة. افتح ⁦Paramètres → Acquisition⁩ وأدخل 22 واحفظ واختر ⁦Dès le début de l'année de congés⁩. الأشهر التي أُضيفت سابقًا بالمعدل القديم لا تتغير: صحّح الفرق بتعديل يدوي عند الحاجة.

8. تسجيل إجازة في 10 ثوانٍ

افتح النموذج بالمفتاح ⁦C⁩، أو بالزر ⁦+ Saisir un congé⁩، أو بالنقر على خانة فارغة في المخطط (يُملأ الموظف والتاريخ تلقائيًا).

  1. الموظف: اكتب حرفين أو ثلاثة ثم ⁦Enter⁩. يظهر آخر 5 موظفين أولًا.
  2. النوع: الإجازة المدفوعة افتراضيًا، والمفاتيح من ⁦1⁩ إلى ⁦9⁩ تغيّر النوع.
  3. التواريخ: اليوم الأول والأخير، أو الاختصارات: اليوم، غدًا، هذا الأسبوع، الأسبوع القادم.
  4. أنصاف الأيام: اليوم الأول «يوم كامل / بعد الظهر»، واليوم الأخير «يوم كامل / صباحًا» (ليوم واحد: كامل أو صباحًا أو بعد الظهر).
  5. تحقّق من السطر المباشر مثل «4.5 أيام عمل (عطلة أسبوعية واحدة وعطلة رسمية واحدة مستثناة)» ومن معاينة الرصيد مثل «12 ← 7.5 أيام» (بالأحمر إن كان سالبًا).
  6. الحفظ: ⁦Ctrl⁩+⁦Enter⁩ (بالحالة الافتراضية) أو ⁦Shift⁩+⁦Ctrl⁩+⁦Enter⁩ (معلّقة). ويبقى زر التراجع 6 ثوانٍ.

اختياريًا: ملاحظة، ومرفق (اسحب أو الصق أو اختر ملف PDF أو JPG أو PNG بحجم أقصاه 10 ميغابايت). تشير علامة مشبك الورق إلى وثيقة إلزامية ناقصة.

إذا غادرت النموذج وفيه تغييرات غير محفوظة (مفتاح ⁦Esc⁩، أو زر الرجوع في المتصفح، أو رابط في القائمة)، يطلب التطبيق تأكيدًا قبل التخلي عنها.

10. المخطط الزمني والأرقام الرئيسية

  • سطر لكل موظف، مجمّعين حسب القسم (انقر على القسم لطيّه). تحت كل قسم سطر يبيّن عدد الغائبين في كل يوم.
  • اللون = نوع الإجازة؛ شريط ممتلئ = مقبولة، مخطّط = معلّقة؛ نصف شريط = نصف يوم.
  • العطل الأسبوعية والرسمية مظلّلة (يظهر الاسم عند التمرير)، وخط عمودي يحدد اليوم.
  • التكبير ⁦W⁩ أسبوع / ⁦M⁩ شهر؛ ⁦←⁩ ⁦→⁩ الفترة السابقة / التالية؛ ⁦T⁩ اليوم.
  • عوامل التصفية (القسم، النوع، الحالة، البحث) تبقى طوال الجلسة وتُطبَّق أيضًا على البطاقات.
  • نقرة على شريط تفتح الإجازة، ونقرة على خانة فارغة تنشئ إجازة جديدة معبّأة مسبقًا.

11. التقارير وتصدير الرواتب

القائمة ⁦Rapports⁩. اختر الفترة: شهر، ربع سنة، سنة، أو فترة مخصّصة.

  • ⁦Récapitulatif mensuel de paie⁩ (ملخص الرواتب الشهري): سطر لكل موظف بالأيام المأخوذة لكل نوع، والأيام بدون أجر، والرصيد في بداية الفترة ونهايتها. الإجازة الممتدة على شهرين تُوزَّع يومًا بيوم.
  • ⁦Détail des congés⁩ (تفاصيل الإجازات): سطر لكل إجازة في الفترة.
  • معاينة على الشاشة ثم تنزيل بصيغة ⁦XLSX⁩ (إكسل) أو ⁦CSV⁩. يُفتح ملف CSV مباشرة في إكسل.
  • زر ⁦Exporter⁩ في الشريط العلوي يصدّر رواتب الشهر الحالي بنقرة واحدة وبآخر صيغة مستعملة.
  • الموظفون المؤرشفون يبقون في تصديرات الفترات التي كانوا يعملون فيها.

13. فهم الأرصدة

  • الرصيد = مجموع قيود السجل حتى تاريخ اليوم.
  • المتاح = الرصيد − الأيام المعلّقة (المحجوزة).
  • القبول يكتب قيد «إجازة» سالبًا، وإلغاء أو رفض إجازة مقبولة يكتب «قيدًا عكسيًا» موجبًا. لا يُمسح أي شيء أبدًا.
  • عند تسجيل إجازة يأخذ الفحص بعين الاعتبار الإجازات المقبولة لاحقًا في السنة حتى لا تُصرف الأيام نفسها مرتين، لذا قد تكون المعاينة أقل من الرقم الظاهر في جدول الموظفين.

14. بوابة الموظفين

لكل موظف فضاؤه الخاص، المصمَّم للهاتف: يطّلع فيه على أرصدته ويطلب إجازة في 15 ثانية. لا يرى إلا بياناته، ولا يرى من زملائه إلا من هو غائب ومتى.

14.1 منح الوصول (جهة الموارد البشرية)

  1. القائمة ⁦Salariés⁩، ثم قائمة سطر الموظف.
  2. موظف له بريد إلكتروني: ⁦Envoyer l'invitation⁩. يتلقى رابطًا صالحًا 48 ساعة، فيختار كلمة مروره ويدخل فضاءه.
  3. موظف بلا بريد: ⁦Mot de passe temporaire⁩. دوّن معرّف الدخول (رمز الموظف) وكلمة المرور، فهما يظهران مرة واحدة فقط، وسلّمهما له. وعليه اختيار كلمة مروره الخاصة عند أول دخول.

عنوان البوابة: ⁦http://localhost:5173/me⁩ محليًا، أو ⁦https://votre-domaine/me⁩ بعد النشر على الإنترنت. وعلى الحاسوب تظهر في عمود وسط الشاشة.

14.2 تسجيل الدخول (جهة الموظف)

  • صفحة ⁦Mon espace congés⁩: البريد أو رمز الموظف ⁦(E-mail ou code salarié)⁩، ثم كلمة المرور، ثم ⁦Se connecter⁩. القواعد نفسها كما لدى الموارد البشرية: 8 أحرف على الأقل، وقفل 15 دقيقة بعد 5 أخطاء، و⁦Rester connecté⁩ لمدة 30 يومًا.
  • نسيان كلمة المرور: زر ⁦Mot de passe oublié ?⁩ إن كان للموظف بريد، وإلا فيطلب كلمة مرور مؤقتة جديدة من الموارد البشرية.
  • رمز الترس أعلى الشاشة يفتح ⁦Réglages⁩ (الإعدادات): اللغة، وتغيير كلمة المرور، والخروج.

14.4 طلب إجازة

  1. زر ⁦Demander un congé⁩.
  2. اختر النوع، ثم المس اليوم الأول واليوم الأخير في التقويم، مع اختيار الصباح أو بعد الظهر عند الحاجة.
  3. تحقّق من عدد الأيام، والرصيد بعد الطلب، وسطر الزملاء الغائبين.
  4. اختياريًا: ⁦Ajouter une note⁩ (ملاحظة) و⁦Ajouter un document ou une photo⁩ (وثيقة أو صورة، وتعمل كاميرا الهاتف).
  5. ⁦Envoyer la demande⁩. ويبقى شريط ⁦Annuler⁩ (تراجع) ظاهرًا 6 ثوانٍ.

14.5 سحب طلب

ما دام الطلب معلّقًا يمكن سحبه بزر ⁦Retirer⁩ دون تأكيد، ويعيده زر ⁦Annuler⁩ إلى الانتظار خلال 6 ثوانٍ. وإذا كانت الموارد البشرية قد قرّرت مسبقًا، يُرفض السحب. أما الإجازة المقبولة فلا تُعدَّل من البوابة: يجب الاتصال بالموارد البشرية.

14.6 المزامنة الفورية

  • يظهر الطلب المرسَل لدى الموارد البشرية في نحو ثانيتين: يزيد رقم الطلبات المعلّقة، ويظهر شريط مخطّط، ويحمل الطلب علامة ⁦Via le portail⁩ (عبر البوابة).
  • عندما تقبل الموارد البشرية الطلب أو ترفضه، تتحدّث شاشة الموظف تلقائيًا بما في ذلك الرصيد. ويُرسَل أيضًا بريد لا يتضمن إلا التواريخ والقرار؛ أما النوع والسبب فلا يظهران إلا بعد تسجيل الدخول.
  • إذا انقطع الاتصال الفوري، تتحدّث الشاشات مع ذلك كل 30 ثانية.
هاتف مشترك: الخروج من الحساب يمسح من الهاتف الطلبات التي تنتظر الإرسال. وإذا دخل شخص آخر من الجهاز نفسه، فلن يرى أبدًا طلبات الموظف السابق ولن يرسلها.
